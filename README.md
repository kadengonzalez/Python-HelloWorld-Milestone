# Python Hello World Milestone

## Overview

This project is an introductory Python milestone focused on learning the core fundamentals of programming in Python.  
The notebook demonstrates how to use variables, strings, the `print()` function, and formatted strings (f-strings) to generate output and build simple messages.

The goal of this exercise was to practice Python syntax and basic debugging while working inside a Jupyter Notebook environment.

---

## Skills & Tools

- Python
- Jupyter Notebook
- Variables
- Strings
- f-strings
- Debugging syntax errors
- Output formatting

---

## Key Concepts Practiced

- Storing text values inside variables
- Printing variables to the console
- Using f-strings to embed variables inside sentences
- Identifying and fixing common string syntax errors
- Combining multiple variables into a single output
- Formatting output with newline characters (`\n`)
